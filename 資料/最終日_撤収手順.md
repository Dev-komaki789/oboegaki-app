## STEP 2：GitHub 側の連携を解除

> **このPCの認証は VSCode 経由になっている。**（2026-08-24 確認：`git push` が
> 何も聞かずに通り、キーチェーンに `acct=274962537`＝GitHub のユーザーID で保存された）
> **PAT を消すだけでは連携が残る。** 下の3つを全部やること。

**① VSCode からサインアウト**

VSCode 左下のアカウントアイコン → GitHub のアカウント → **Sign Out**

**② OAuth App の連携を解除**

https://github.com/settings/applications → **Authorized OAuth Apps**
→ **`Visual Studio Code`** を **Revoke**
（`GitHub for VS Code` / `Git Credential Manager` が並んでいれば、それらも Revoke）

> ⚠️ **`Vercel` は Revoke しないこと。**
> これは訓練校PCとは無関係の、サーバー同士の連携。消すと**自動デプロイが止まり、
> 退校後に自宅から push しても本番に反映されなくなる。**
> このページで「全部消す」をやらないこと。**消すのは PC の認証経路だけ**。
>
> | 連携 | 撤収時 | 理由 |
> |---|---|---|
> | `Visual Studio Code` | **Revoke** | この PC が GitHub に入る経路 |
> | `Vercel` | **残す** | PC を経由しない。消すとデプロイが壊れる |

**③ PAT を削除**

https://github.com/settings/tokens → 該当トークンを **Delete**

> **使っていなくても必ず消す。** 今回 push に使われたのは VSCode 側の認証で、
> 自分で発行した PAT は未使用のまま GitHub に残っている。存在を忘れやすいので、
> 「使っていないから大丈夫」と飛ばさないこと。

## 退校後も自宅PCで続ける場合

リポジトリは個人アカウント `Dev-komaki789` にあるので、**clone すればそのまま続けられる。**

```
# git clone https://github.com/Dev-komaki789/oboegaki-app.git
# cd oboegaki-app/web
# npm install
```

そのあと `web/.env.local` に Supabase の URL と anon key を書けば動く。

### clone しても降りてこないもの

| もの | 理由 | 対処 |
|---|---|---|
| **`20260818/`（約11MB）** | `.gitignore` で除外 | **STEP 0 で必ず持ち出す** |
| **`おぼえがき.pptx`** | 同上 | 同上 |
| `web/.env.local` | 鍵なのでコミットしていない | Supabase の管理画面から取り直す |
| `web/node_modules/` | 自動生成 | `npm install` |

**`20260818/` と `.pptx` は GitHub に無い。clone しても絶対に戻らない。**

### ⚠️ Revoke の順番

STEP 2 の Revoke は**アカウント単位**で効く。自宅PCで先に GitHub へサインインしていると、
訓練校PCの撤収で**自宅PC側の認証も一緒に切れる**。

```
1. 訓練校PCで撤収を全部終わらせる（STEP 2 の ①②③）
2. そのあとで自宅PCにサインイン／自宅用の PAT を発行する
```

順番を逆にすると、自宅PCの認証を作り直すことになる。
