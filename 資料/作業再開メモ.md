## 6. 設計書と違う判断（引き継ぎ書を読んで迷わないように）

### DB

| 箇所 | 判断 | 理由 |
|---|---|---|
| `auth.users` → `public.users` のトリガー | §4 に無いが**追加** | Supabase の認証は `auth.users` にしか行を作らない。橋渡しが無いと `people` を1件も登録できない |
| RLS の `users`／`keywords`／`topics` | §4 に SQL が無いので**補った** | `users` のポリシーが無いと自分の行すら読めない |

### 計算

| 箇所 | 判断 | 理由 |
|---|---|---|
| 日数の差 | **`differenceInCalendarDays`** | `talked_at`（date型）と `new Date()`（時刻あり）を混ぜると夜間に1日多く数える |
| `lib/recalc.ts` を新設 | §6 の④⑤⑥を共通化 | 保存・修正・削除で同じ計算をする。2箇所に分かれると必ずずれる |
| 記録が0件になった話題 | **行ごと削除** | 残すとスコア0の泡が枠を1つ無駄にする |

### 画面

| 箇所 | 判断 | 理由 |
|---|---|---|
| バッジの「+N」 | **実装しない** | 文字幅をサーバーで見積もる必要があり割に合わない。`max-h-16` で2行に制限 |
| バッジの位置 | **名前の列の外**（カード幅いっぱい） | よみがなを上に移して右カラムが2行で終わり、右隣が空いていた。176px → 286px |
| 検索 | **入力するたびに走る** | スマホ中心のため。変換中は検索しない |
| 一覧のよみがな | **名前の上**（モックアップは横並び） | 横並びだと名前に176pxしか使えず「中村 あゆみ」で省略される |
| 明細の点数 | `text-name` / `accent-500` | §9 は「控えめに小さく」だが `text-caption` では読めなかった |
| 画面幅の上限 | 390px → **430px**（フォームは560px） | 大きい端末で両端が余る |
| 時系列／話題別 | **クライアント側で切り替え** | 開発ログ06 は「クエリで持つ」だったが、切り替えのたびに4本のクエリを投げ直していた。URL は `history.replaceState` で維持 |
| バブルの半径 | `range([0, 64])` ＋ 透明な当たり判定24px | §9 の「24px」の根拠は「指で押せる下限」。見た目の下限にすると差が読めない（1.75倍 → 3.16倍） |
| バブルのキャンバス | **泡の数に応じて可変** | 固定だと8話題で占有70%になり枠から溢れた。`heightFor(n)` / `maxRadiusFor(n,h)` で占有25〜40%に |
| バブルの動き | **登場と押下のときだけ** | 常時揺らすと酔う。CSS アニメーションで JS のループを回さない |
| **「前回話した」の表示** | **やめた** | §9 は薄いグレーで塗りつぶす設計。だが塗ると点数が読めない。色・枠でも凡例なしでは伝わらず、**泡の中に最終会話日が出ているので重複だった** |
| 「戻る」 | **pop（`router.back()`）** | `replace` は履歴を縮めない。タブと保存後だけ `replace` |
| エラーの位置 | **その入力欄のそば** ＋ 画面外なら自動スクロール | 下に出していて Enter 送信時に気づけなかった |

### 仕様に無い追加

| 追加 | 理由 |
|---|---|
| お客さんの編集・削除 | §9 S-04 に「編集」リンクはあったが行き先が未定義だった |
| **記録の修正・削除** | **実機でスライダーが飛び、違うスコアで保存された。** 帯タップで値が飛ぶのは `range` の標準挙動で防げない。記録画面にも ±1 ボタンを追加 |
| 設定画面（ログアウト） | ログアウトの手段が無かった |

### タブレット

| 箇所 | 判断 | 理由 |
|---|---|---|
| **別ルートを作らない** | 同じ画面に `lg:` の分岐 | 別々に作ると同じ画面を2つ保守することになる |
| サイドバーだけブラウザ側で取得 | `layout.tsx` は `searchParams` を受け取れない | 検索を持たせるにはこの形が必要。RLS はブラウザでも効く |
| サイドバーの検索は URL を変えない | 変えると右ペインまで切り替わる | |
| 下部固定ボタン | lg では**固定をやめる** | `fixed inset-x-0` ＋ `mx-auto` は画面全体基準なので、サイドバーぶん左にずれる |
| モックアップの無い画面 | 中央寄せで幅だけ 560px | 一覧・登録・編集・設定・記録修正。横に広げすぎると視線の移動が長くなる |

## 7. 性能（2026-08-25 計測）

実機で**1タップ4秒**だったものを**1秒以下**にした。

| 対処 | 効果 |
|---|---|
| **Vercel の実行リージョンを東京（hnd1）に** | **4秒 → 1秒。** 既定はアメリカ東部で太平洋を往復していた |
| 問い合わせを `Promise.all` に | 3〜4回 → 1回 |
| `loading.tsx` ＋ `prefetch` | 押した瞬間に骨組み／先に取りに行く |
| 時系列／話題別をクライアント切り替えに | 往復ゼロ |

**下限は 126ms**（DBを引かない画面の応答）。コールドスタート 310〜685ms は無料枠では避けられない。
**発表直前に何度かタップして温めておく。**

## 8. ハマった点（同じ症状が出たとき用）

| 症状 | 原因 | 対処 |
|---|---|---|
| `モジュール '@supabase/ssr' が見つかりません` | `web/node_modules` が無い | `cd web && npm install` → `TypeScript: Restart TS Server` |
| `ENOENT: _buildManifest.js.tmp` | **dev 中に `npm run build`** して `.next` が壊れた | dev を止めて `rm -rf .next` |
| `Invalid login credentials` | エラー文言を1種類に統一しているので原因が分からない | `console.error` を `npm run dev` のターミナルで見る |
| Table Editor で行が見えない | RLS が効いている**正常な状態** | SQL Editor からは見える |
| バッジの楕円が潰れる | **flex は次の行へ送る前にまず縮む** | `shrink-0 whitespace-nowrap` |
| 変換途中のローマ字で検索が走る | IME の変換中も `onChange` が発火 | `compositionstart` / `compositionend` |
| 本番だけ重い | Vercel の実行リージョンがアメリカ東部 | Settings → Functions → Tokyo → **Redeploy** |
| 戻るで同じ画面を何度も遡る | 戻る系が `<Link>`（履歴に積む）だった | `router.back()`。**`replace` では縮まない** |
| PWA がインストールできない | `/manifest.json` が middleware に弾かれて 307 | matcher の除外に追加 |
| ゆっくりスクロールでキーボードが閉じない | スクロール**量**で判定していた | **`touchmove`（指で動かしたか）で判定** |
| PWA アイコン生成が崩れる | Chrome ヘッドレスに**最小ウィンドウ幅**がある | 512 で描いて `sips -z` で縮小 |
| **`key` の警告が出る** | **Server → Client に JSX を prop で渡すと、配列が境界を越えるとき誤検知する** | **配列を境界で作らない。**部品に切り出す |
| **タブレットで固定ボタンが左にずれる** | `fixed inset-x-0` ＋ `mx-auto` は**画面全体基準** | lg では固定をやめる |
| **サイドバーの検索が会社名を見ていなかった** | 一覧本体とは別に書いたため、項目が揃っていなかった | 4項目に揃える。**片方だけ直す実装は必ずずれる** |
