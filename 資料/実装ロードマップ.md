## 4. 順序を変えてはいけないところ

| 先 | 後 | 理由 |
|---|---|---|
| Day1 空デプロイ | 機能実装 | 環境変数とビルド設定で時間が溶ける。5日では致命傷 |
| `lib/score.ts` | S-08 記録する | 保存はできてもスコアが動かない |
| S-04/05 情報タブ | S-06 バブル | **主目的は情報タブで達成する。** バブルは「あると強い」だけ |

`records.score` / `talked_at`、`people.company` / `position` / `group_id` は **DDL に既に入っている**ので追加対応は不要。
